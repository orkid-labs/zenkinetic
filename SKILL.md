# zenkinetic

zenkinetic is the admission gate for the Horizen L3 privacy stack: it scores confidential transactions with the negentropy engine and applies ZEN-token staking rules before they reach the privacy pool. Ships as a CLI.

## When to use

Operating or integrating with Orkid's Horizen Base L3 privacy infrastructure.

## Install

```
cargo install zenkinetic
```
